# CLI コマンド仕様

要件定義書 17 章「CLI機能」の詳細仕様。

## 共通事項

### グローバルオプション

サブコマンドの前後どちらにも書ける。

| オプション | 説明 |
| --- | --- |
| `--dir DIR` | tasks.md を置くディレクトリ |
| `--yes`, `-y` | 確認を省略する |
| `--json` | JSON で出力する |
| `--no-prompt` | 再配置・アーカイブの提案をしない |
| `--version` | バージョンを表示する |
| `-h`, `--help` | ヘルプを表示する |

`todos --yes archive` と `todos archive --yes` は同じ意味。

### 環境変数

| 変数 | 説明 |
| --- | --- |
| `TODOS_DIR` | tasks.md を置くディレクトリ |
| `EDITOR` / `VISUAL` | 外部エディタ（`VISUAL` を優先） |
| `TODOS_AMBIGUOUS_WIDTH` | `2` で曖昧幅文字を全角扱い |
| `TODOS_TODAY` | 基準日を固定する（テスト用） |
| `TODOS_TUI_THEME` | TUI の配色（`dark` / `light` / `basic` / `mono`） |
| `TODOS_TUI_GLYPHS` | `0` で TUI の記号・罫線を ASCII に落とす |
| `TODOS_TUI_POWERLINE` | `1` で TUI のステータスバーに Nerd Font の区切りを使う |
| `NO_COLOR` | 設定されていれば TUI で色を使わない |

### タスクの指定子

`SELECTOR` には次のどちらかを渡す。

- 一覧上の表示番号（`todos list` の左端の数字）
- タイトルの部分一致（完全一致があればそれを優先）

複数該当した場合、対話実行では候補を提示して選択させ、非対話実行では
変更せず終了コード 2 を返す。

### 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 正常終了 |
| 1 | エラー、確認の中止、`validate` で問題を検出 |
| 2 | タスクを一意に特定できなかった |

## todos

引数なしで TUI を起動する。詳細は `docs/tui.md`。

## todos init

`tasks.md` と `archive.md` を作成する。既にあれば何もしない。

他のコマンドを実行したときに `tasks.md` が無ければ自動で作成するため、
通常は明示的に実行しなくてよい。

## todos add TITLE

タスクを追加する。必須はタイトルのみ。

| オプション | 説明 |
| --- | --- |
| `--status`, `-s` | ステータス（既定: 未着手） |
| `--who` | 要返答・回答待ちの相手 |
| `--due`, `-d` | 期日 |
| `--tag`, `-t` | タグ（複数指定可） |
| `--detail` | 詳細文（改行可） |
| `--section` | 配置先（既定: 期日とステータスから自動判定） |
| `--parent` | 親タスクの指定子。子タスクとして追加する |

```sh
todos add "READMEを書く"
todos add "リリース準備" -d 2026/07/31 -t release
todos add "レビューに回答する" -s 要返答 --who 山田 -d 2026/07/28
todos add "CLIコマンドを整理する" --parent 2
```

`--parent` と `--section` は併用できない（子タスクは親と同じセクションに置かれる）。

## todos list [SECTION]

セクションごとにタスク一覧を表示する。

| オプション | 説明 |
| --- | --- |
| `SECTION` | セクション名で絞り込む |
| `--status`, `-s` | ステータスで絞り込む |
| `--tag`, `-t` | タグで絞り込む |

このコマンドの実行時にだけ、再配置とアーカイブの提案を行う。

```sh
todos list
todos list Today
todos list --tag backend
todos list --json
```

## todos show SELECTOR

タスクの詳細（ステータス・期日・タグ・詳細文・子タスク）を表示する。

## todos edit SELECTOR

タスクを編集する。フィールド指定のオプションを1つも渡さない場合は
外部エディタ（`$VISUAL` / `$EDITOR`）を開く。

| オプション | 説明 |
| --- | --- |
| `--title` | タイトルを変更する |
| `--due`, `-d` | 期日を設定する |
| `--clear-due` | 期日を削除する |
| `--add-tag` | タグを追加する（複数指定可） |
| `--remove-tag` | タグを削除する（複数指定可） |
| `--detail` | 詳細文を差し替える |
| `--editor`, `-e` | 外部エディタを開く |

外部エディタにはタスク1件分の Markdown（子タスク・詳細文を含む）を渡す。
保存された内容を解析し直して取り込むため、子タスクの追加や削除もできる。

## todos status SELECTOR STATUS

ステータスを変更する。`--who` で要返答・回答待ちの相手を指定できる。

ステータスと同時に、チェックボックスと取り消し線も更新する。

```sh
todos status 3 進行中
todos status "レビュー" 回答待ち --who デザインチーム
```

## todos done SELECTOR / todos skip SELECTOR

`todos status SELECTOR 完了` / `todos status SELECTOR やらない` の別名。

未完了の子タスクを持つ親を終了させようとした場合は確認する。
非対話実行では `--yes` が必要（無い場合は変更せず終了コード 1）。

## todos move SELECTOR SECTION

タスクを別セクションへ移動する。子タスクは親と一緒に移動する。
子タスクを単独で移動することはできない。

移動結果は次回の自動再配置で再評価される。

## todos search [KEYWORD]

タイトルと詳細文をキーワードで検索する。

| オプション | 説明 |
| --- | --- |
| `--tag`, `-t` | タグで検索する |
| `--status`, `-s` | ステータスで絞り込む |
| `--section` | セクションで絞り込む |

```sh
todos search レビュー
todos search --tag backend
```

## todos rollover

すべての未完了タスクを共通ロジックで再評価し、セクションを振り直す。
Tomorrow から Today への単純な移動ではない。

移動内容を表示してから確認する。`--yes` で確認を省略できる。

再配置後、期日が迫っている保留タスクがあれば判断を促す。

## todos archive

終了ステータス（完了・やらない）のタスクを `archive.md` へ移す。
親タスクは子孫を含めて丸ごと移動する。

終了した子タスクは、親が終了するまで元の場所に残る。

## todos report today

日報作成用の候補一覧を出力する。

- 手を付けたタスク（候補）: 進行中・要返答・回答待ち
- 完了したタスク（候補）: 未アーカイブの完了
- やらないと判断したタスク: 未アーカイブのやらない

履歴を保持しないため、当日の作業であることは保証しない。

## todos validate [--fix]

構文検証を行う。検出する問題:

- 未知のステータス
- 認識できない期日
- 正規形式ではない日付
- 完了ステータスとチェックボックスの不一致
- やらないステータスと取り消し線の不一致
- 親が完了しているが未完了の子が存在する
- 必須セクションが存在しない
- タスクとして解釈できない箇条書き
- 既知セクション外の見出し配下にあるタスク行

`--fix` を付けると、安全に直せるものについて 1 件ずつ確認して修正する。
`--yes` を併用すると確認を省略する。

問題が残っている間は終了コード 1 を返すため、CI などでも使える。

## todos tui

TUI を起動する（引数なしの `todos` と同じ）。

## AI エージェントからの利用

```sh
todos list --json          # 一覧を取得
todos show 3 --json        # 1件の詳細を取得
todos report today --json  # 日報候補を取得
todos add "タスク名" --json # 追加結果を取得

todos rollover --yes       # 確認なしで再配置
todos archive --yes        # 確認なしでアーカイブ
todos validate --json      # 問題の一覧を取得
```

- JSON によるタスク入力は MVP 対象外。
- 対象を一意に特定できない場合は変更せず終了コード 2 を返す。
- 引数なしの `todos`（TUI）は利用経路として想定しない。
