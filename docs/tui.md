# TUI 仕様

要件定義書 18 章「TUI機能」および 25.6「TUIの画面仕様」の詳細。

## 位置付け

キーボード中心で操作するタスクダッシュボード。
汎用 Markdown エディタや Vim 互換エディタとしては実装しない。
複数行の本文編集は外部エディタへ委譲する。

Markdown の書き換えは CLI と同じ `ops` / `schedule` / `validate` を経由する。
TUI が独自にファイルを書き換えることはない。

## 起動

```sh
todos
todos tui
```

起動時に再配置またはアーカイブが必要と判断した場合、フッタ行で確認する。
`--no-prompt` を付けると確認しない。

起動時は **タスクがある最初のセクション** を選択する。Today が空でも
「タスクが1件も見えない画面」にならないようにするため。全セクションが空の場合は
Today を選択する。

## 画面レイアウト

```
┌ Sections ──────┬ Tasks ──────────────────────────────────────────┐
│ Today        3 │> 【要返答（山田）】レビュー対応（〜2026/07/28）  │
│ Tomorrow     · │  APIを実装する                                  │
│ InWeek       1 │  READMEを書く                                   │
│ OpenEnded    2 │    子タスク                                     │
│ ParkingLot   5 │                                                 │
├────────────────┴─────────────────────────────────────────────────┤
│j/k:移動  J/K:セクション  Enter:詳細  a:追加  s:状態  ?:ヘルプ    │
│ Today  1/3  /Users/me/todos/tasks.md                             │
└──────────────────────────────────────────────────────────────────┘
```

- 左ペイン: セクション一覧と件数（トップレベルのタスク数。0 件は `·`）
- 右ペイン: 選択中セクションのタスク。子タスクはインデントして表示
- 下から 2 行目: キーヘルプ（端末幅に合わせて表示する項目を減らす。
  `?:ヘルプ` と `q:終了` は幅が狭くても必ず残す）
- 最下行: 現在位置・ファイルパス・操作結果メッセージ

選択行は反転表示する。フォーカスの無いペインの選択行は太字で示す。

タスクが 1 件も無いセクションでは、右ペインに
`(タスクなし)  j/k または J/K でセクション移動` と表示する。
検索結果が空の場合は `該当なし  Esc で解除` と表示する。

## キー割り当て

| キー | 動作 |
| --- | --- |
| `j` / `↓` | 次のタスクへ（セクションが空なら次のセクションへ） |
| `k` / `↑` | 前のタスクへ（セクションが空なら前のセクションへ） |
| `g` / `G` | 先頭 / 末尾へ |
| `h` | セクションペインへ |
| `l` | タスクペインへ |
| `Tab` | セクションペインとタスクペインを切り替える |
| `J` / `K` | 次 / 前のセクションへ |
| `Enter` | タスクの詳細を表示 |
| `a` | タスクを追加 |
| `i` | タイトルを簡易編集 |
| `s` | ステータスを変更 |
| `d` | 完了にする |
| `x` | やらないにする |
| `m` | セクションを移動 |
| `/` | キーワード検索 |
| `t` | タグ検索 |
| `Esc` | 検索結果を解除 |
| `r` | 自動再配置 (rollover) |
| `A` | アーカイブ |
| `w` | 構文上の警告を表示 |
| `e` | 外部エディタで編集 |
| `R` | ファイルを読み直す |
| `?` | ヘルプ |
| `q` | 終了 |

キー割り当ての変更は MVP 対象外。

## モーダル画面

### 選択モーダル（ステータス変更・セクション移動）

中央に一覧を表示する。`j`/`k` で移動、`Enter` で決定、`Esc` で中止。
数字キーで直接選択もできる。

### 入力モーダル（追加・タイトル編集・検索）

最下行を入力欄として使う。`Enter` で確定、`Esc` で中止。
日本語入力も受け付ける（`get_wch` で 1 文字ずつ読む）。

### 表示モーダル（詳細・警告・ヘルプ）

中央に枠付きで表示する。`j`/`k` でスクロール、任意のキーで閉じる。

### 確認（y/N）

最下行に `[y/N]` を表示する。`y` 以外は「いいえ」として扱う。

## 検索 UI

`/` または `t` で入力欄を開き、確定すると右ペインが検索結果表示に切り替わる。
検索結果の各行にはセクション名を `[Today]` の形で前置する。

`Esc` またはセクション移動で通常表示に戻る。

## ステータス選択 UI

7 つの固定ステータスを一覧表示する。
`要返答` / `回答待ち` を選ぶと、続けて相手の入力欄が開く（空欄可）。
`完了` / `やらない` を選んだ場合は `d` / `x` と同じ経路を通り、
未完了の子タスクがあれば確認する。

## 外部ファイル更新の検出

MVP では自動検出しない。要件 24-8 のとおり、TUI 起動中に外部から
tasks.md を編集した場合の対応は保証しない。

`R` キーでファイルを読み直せる。読み直すと選択位置は先頭に戻る。

TUI 側の操作は 1 操作ごとに tasks.md へ書き戻すため、
外部編集と競合した場合は後から書いた方が残る。

## 端末サイズが不足する場合

幅 40 桁・高さ 10 行を下回る場合は描画をやめ、
`端末が小さすぎます (40x10 以上必要)` と表示する。
端末を広げれば通常表示に戻る（リサイズは自動で追従する）。

## 対応環境

- UTF-8 を扱える端末（xterm 系、iTerm2、Terminal.app、GNOME Terminal、tmux など）
- 罫線がずれる場合は環境変数 `TODOS_AMBIGUOUS_WIDTH=2` を指定する

## MVP 対象外

- Vim 互換のモードやコマンド
- 高度な複数行インライン編集
- Undo / Redo
- 任意のキー設定変更
- マウス操作・ドラッグ操作
- Markdown の完全な装飾表示
- 複雑な画面分割
- プラグイン機構
